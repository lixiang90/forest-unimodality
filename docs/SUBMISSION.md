# Submission preparation

The repository is a public development candidate. Acceptance as a complete Lean contribution still requires:

- Import the entire final theorem and exported entry closure from the accepted
  development rebuild, with byte-for-byte source hashes and fixed dependencies.
- Check the final committed statement against the original all-forest problem.
- Test the documented portable setup, fresh project build and final axiom audit;
  retain the exact commands, outputs and source commit.
- Supply accurate public contributor identities and contribution descriptions,
  record AI assistance, and select a distribution license.
- Record the original contributor-owned repository URL, branch
  and full proof commit; confirm branch containment and attributable history.
- Refresh the related-submission search and the official requirements, then
  complete the draft PR using only actual public evidence.

The awards repository receives catalog references and attribution, while Lean
source stays in the external proof repository. Mathematical review is a separate
prerequisite for accepting the Lean contribution.

[Contribution rules](https://github.com/TheJustinSunPrize/awards/blob/main/CONTRIBUTING.md),
[verification](https://github.com/TheJustinSunPrize/awards/blob/main/docs/verification.md),
[attribution](https://github.com/TheJustinSunPrize/awards/blob/main/docs/attribution.md),
[award process](https://github.com/TheJustinSunPrize/awards/blob/main/docs/award-process.md).

Candidate publication, public review, identity verification, written confirmation
and the official award announcement remain separate later steps. Repository
creation, a local build, or a merged PR does not establish an award.
