# Attribution and provenance

## Mathematical source

The fixed mathematical reference is Tong Zhang, *Exact Certificates for
Unimodality of Forest Independence Polynomials*, September 26, 2026, repository
commit `7cee5104a983dd1271db14be7606e96c504aa370`. Relevant material includes
Theorem 1.1, the assembly, Sections 2–5 and the required Supplements A/B.
[Fixed manuscript](https://github.com/zhangzenozhang-jpg/-forest-unimodality-proof/blob/7cee5104a983dd1271db14be7606e96c504aa370/paper/forest_unimodality_Tong_Zhang.pdf).

This attribution concerns that exact version. A later public author message
mentions a manuscript titled *Unimodality of Forest Independence Polynomials*
with Tong Zhang and Wei Li. That later version has not replaced the fixed source
used here. [Version discussion](https://github.com/selfreferencing/erdos-993/issues/1).

The original question is Problem 3 in Alavi, Malde, Schwenk and Erdős,
*The Vertex Independence Sequence of a Graph Is Not Constrained* (1987),
PDF page 7 / printed page 21.
[Original paper](https://www.renyi.hu/~p_erdos/1987-33.pdf#page=7).
